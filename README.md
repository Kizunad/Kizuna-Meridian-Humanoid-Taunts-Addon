# Kizuna 经脉类人垃圾话

Minecraft 1.20.1 Fabric 附属：Vanilla-Humanoid-Threatening 认领的生人（村民、流浪商人与五种灾厄村民）
经 Vanilla-Damage 受击时朝攻击者吐一句垃圾话。攻击者是玩家时台词里是玩家名，是其他生物时是该生物的翻译名；
附近玩家在聊天栏看到浅灰色的「<说话者> 台词」，说话者头顶同时出现 4 秒的说话气泡（像素圆角框、底部小尾巴指向头顶，半透明白底黑字）。

行为、命令、配置、台词数据、整合接口与验证记录统一维护在 [Wiki](docs/wiki/Home.md)。
