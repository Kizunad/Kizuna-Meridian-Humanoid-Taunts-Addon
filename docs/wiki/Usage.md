# 使用方法

## 触发

说话者是 Threatening 认领、且当前台词表里有该实体 ID 的生人。它经 Vanilla-Damage 受到伤害、身体事务提交后：

1. 没有生物攻击者（摔落、着火、溺水、无主弹射物等）不说；攻击者是它自己不说；
2. 这一击后身体已死亡（致死一击）不说；
3. 同一实体上一句之后不足冷却时间（默认 6 秒）不说，冷却期间的受击不排队；
4. 攻击者是玩家，从 `to_player` 抽；是其他生物（包括类人互殴、被铁傀儡打），从 `to_entity` 抽；
5. 同一实体最近说过的 5 句不会再抽到；这 5 句按说出的先后计，两组台词合用一个窗口。

冷却与最近台词按实体对象记在内存里，实体卸载或服务端重启后从零开始。

## 台词里的名字

台词里的 `{attacker}` 替换为攻击者的名字组件 `getName()`：

- 玩家是玩家名；
- 其他生物是实体类型的可翻译名（如 `entity.minecraft.vindicator`），由每个客户端按自己的语言解析；
- 被命名牌改过名的生物用自定义名字，与说话者名字的规则一致。

## 显示

两种显示都只发给说话者 16 格内（含 16 格）的玩家：

- **聊天**：浅灰色的「<说话者> 台词」，复用原版聊天格式键 `chat.type.text`；说话者名字有自定义名字时用自定义名字，
  否则是实体的默认名字（村民按职业，如「农民」）。这是系统消息，不进玩家聊天签名链。
- **气泡**：说话者头顶 4 秒的说话气泡，随实体移动，始终面向镜头；离镜头超过 16 格不画，
  被方块挡住时不透视。台词超过 120 像素宽时换行，换行守避头尾规则：句读号与结束引号、括号不放行首
  （单个时挂在上一行末尾，该行最多超出一个字宽；连续几个时把上一行最后一个字一起带下来），
  开引号与左括号（「『（ 等）不留行尾，英文与数字串（玩家名）不拆开、整串换到下一行，比一行还长时才拆。
  同一实体的新台词替换旧气泡并重新计时。
  形状是原版风格的像素圆角框：最外两行逐行内缩 2、1 个字体像素，四角各缺一个小台阶；
  底部正中一条 4 像素高的三角尾巴（自上而下 8、6、4、2 像素宽），尖端对准头顶上方 0.6 格。
  文字四周留 2 像素，底色半透明白（不透明度 0xC0），文字黑色，无描边。
  气泡由本模组客户端绘制，客户端没装本模组时服务端不发气泡包，只有聊天。

## 命令

本模组在 `/meridian humanoid` 下登记调试命令 `taunt`，让目标立刻说一句；写法、权限与补全见
[Framework 指令页](https://github.com/Kizunad/Kizuna-Meridian-Mod-Framework/wiki/Commands#humanoid)。

不写台词对象时，执行者是玩家用「对玩家」台词，否则用「对生物」台词；写了 `player` 或 `entity` 就固定用对应的一组。
台词里的名字是执行者的名字；从控制台或命令方块执行时是命令源的显示名。
命令不看冷却和死活，但同样记入冷却与最近台词。目标不是生物、不是 Threatening 物种或台词表里没有它时，
命令失败并提示「…没有垃圾话台词」。

## 配置

首次启动在配置目录导出 `meridian-humanoid-taunts.toml`：

```toml
language = "zh_cn"
cooldown_seconds = 6.0

[display]
chat = true
bubble = true
```

| 键 | 含义 | 校验 |
| --- | --- | --- |
| `language` | 台词文件 `taunts/<language>.json` | 小写字母，可带一个 `_` 段，如 `zh_cn`、`en_us`；文件不存在时启动失败 |
| `cooldown_seconds` | 同一实体两句的最小间隔，按 20 tick/秒取整 | 0–3600，整数或小数 |
| `display.chat` | 是否发聊天行 | 布尔 |
| `display.bubble` | 是否发气泡包 | 布尔 |

任一项缺失或越界都在启动时报出具体键名并停止加载，不静默回退默认值。

## 台词数据

台词表在 `data/meridian_humanoid_taunts/taunts/<language>.json`，随 JAR 发布：

```json
{
  "schema_version": 1,
  "species": {
    "minecraft:vindicator": {
      "voice": "卫道士",
      "to_entity": ["…{attacker}…"],
      "to_player": ["…{attacker}…"]
    }
  }
}
```

- `schema_version` 必须是数字 1；`species` 至少一项，键是实体 ID；
- `to_entity` 与 `to_player` 都至少 6 条（多于不重复窗口的 5 条），每条是字符串、恰含一个 `{attacker}`、
  去掉占位符后不为空白；
- `voice` 只给人看，加载时忽略。

当前只有 `zh_cn`。台词由交接目录里两个模型的生成稿去重合并而来，原稿不进 JAR，不在仓库里手写台词。

## 语言切换

台词语言是服务端配置 `language` 选的一份，全服统一；
攻击者与说话者的生物名仍是可翻译组件，按各客户端语言显示。以后有了 `en_us.json`，把 `language` 改成 `en_us` 即可。
1.20.1 服务端拿不到每个客户端的语言设置，所以当初这样设计；迁到 26.2 时行为不变。
26.2 的 `ServerPlayer.clientInformation()` 已带客户端语言，按每个玩家的客户端语言选台词列为后续工作。

## 可能的干扰效果

用户原话是「吐垃圾话干扰」。首版只做显示，不加任何减益；以下候选等用户选择后再做：

| 候选 | 表现 | 作用对象 | 需要决定的事 |
| --- | --- | --- | --- |
| 短暂失焦 | 被骂的玩家屏幕边缘短暂模糊或暗角 0.5–1 秒 | 只对 `to_player` 的攻击者 | 是否受冷却限制、是否叠加 |
| 准星抖动 | 准星在 0.5 秒内小幅随机偏移，不改实际朝向 | 只对 `to_player` 的攻击者 | 抖动幅度；是否影响远程武器的实际弹道 |
| HUD 闪字 | 台词以大号字在屏幕中央闪现 1 秒后淡出 | 只对 `to_player` 的攻击者 | 是否与聊天、气泡重复；位置是否避开准星 |

候选都只在客户端表现，不改伤害结算；做之前需要定是否给配置开关，以及不同物种（如女巫、唤魔者）是否有不同效果。
